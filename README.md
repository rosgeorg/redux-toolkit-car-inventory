# Getting Started with Cars take home test

## Application functionality

1. A list of cars (with name and cost) is stored in a local JSON database. The local JSON database is accessed using a local REST API defined below.
2. Cars can be added and deleted.
3. Users can filter the list of available cars based on car name.
4. A sum of the total cost of all cars is displayed.

## Tasks

1. Implement GET request to the API to retrieve and display cars from the local JSON database.
2. Implement POST request to the API to create a new car in the local JSON database.
3. Implement DELETE request to the API to delete an existing car by ID in the local JSON database.
4. Implement filter functionality which will filter the list of displayed cars based on the provided filter term and car name.
5. Display the total cost of all cars.

Implementation in Redux Toolkit is preferred but not mandatory.

## Running the application

In the project directory, open a terminal window and run the following to start up the client application:
`npm install`
`npm start`

In a separate terminal window, start up the local REST API by running the following:
`npm run start:server`

View the existing database structure within `db.json`

## API endpoints

### Retrieve a list of cars in the local JSON database

`GET http://localhost:3005/cars`

### Add a new car to the local JSON database

`POST http://localhost:3005/cars`

Sample POST request body:
{
    name: car.name,
    cost: car.cost,
    id: autogenerated_id
}

### Delete a car from the local JSON database

`DELETE http://localhost:3005/cars/${car.id}`
